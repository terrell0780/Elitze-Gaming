# ELITZE GAMING

AI-native full-stack game creation platform.

## Core
- Chat for game creation and project-aware collaboration.
- Global Search across game-development sources and documentation.
- Agent Reach for controlled project/tool execution.
- Content Agents for code, 3D, characters, weapons, animation, world, NPCs, quests, audio, VFX, QA, optimization, and release.
- 3D Asset Lab: upload, 360° inspection, repair, restyle, rig, animate, optimize, validate, and bring assets into a game.
- Intelligent Roleplay for persistent NPC memory, personality, relationships, schedules, factions, dialogue, and world-aware decisions.
- Remix & Evolve for projects explicitly marked remixable, with license/attribution controls.
- Game Template Library using genre/mechanic templates inspired by popular game formats without copying protected game content.
- Unreal, Unity, and Roblox integration targets.

## Flagship Game Direction
Cyberpunk survival with base building, AI companions, AI base guards, factions, intelligent roleplay, vehicles, crafting, loot, and persistent multiplayer.

## Quality Standard
AAA visual quality, agent-native development, creator-friendly workflows, and deterministic validation before assets or code are marked game-ready.

## Repository Boundary
This repository is the dedicated ELITZE Gaming project. It is independent of `ELITZE-SENTINEL-FULL`.
