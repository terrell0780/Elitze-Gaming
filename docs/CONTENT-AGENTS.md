# ELITZE GAMING — CONTENT AGENT SYSTEM

## Director

### Game Director Agent
Owns the game objective, decomposes requests, delegates to specialists, checks dependencies, and coordinates final acceptance.

## Production Agents

- Game Design Agent — core loop, systems, progression and balancing.
- World Builder Agent — terrain, districts, POIs, interiors, procedural layouts and world states.
- Level Design Agent — encounter spaces, traversal, combat spaces and mission layouts.
- Character Agent — original characters, appearance, equipment and game configuration.
- Weapon Agent — original weapon concepts, stats, materials, animation requirements and integration data.
- Vehicle Agent — original vehicles, handling data, damage model and integration requirements.
- Creature Agent — creatures, taming, breeding, stats, behaviors and animation requirements.
- NPC / Roleplay Agent — NPC identity, memory, personality, schedules, dialogue, relationships and faction alignment.
- Companion Agent — player companion planning, memory, personality, combat and utility behaviors.
- Base Guard Agent — patrol, threat detection, defense priorities, reporting and repair behaviors.
- Quest Agent — objectives, rewards, dependencies, branching and dynamic mission generation.
- Faction Agent — factions, territory, relationships, reputation and conflict state.
- Economy Agent — resources, shops, prices, sinks, rewards and balancing.
- Building Agent — structures, modular pieces, placement rules, materials and damage states.
- Animation Agent — rigs, retargeting, state machines, blends, locomotion and combat animation requirements.
- 3D Asset Agent — model preparation, topology, UVs, materials, LODs, collision and export.
- VFX Agent — particles, impacts, environmental effects and performance constraints.
- Audio Agent — SFX specifications, implementation events and mix requirements.
- Music Agent — dynamic music states and transition rules.
- UI/UX Agent — HUD, menus, inventory, interaction states and accessibility.
- Cinematic Agent — shots, cameras, sequences, dialogue timing and render targets.
- Multiplayer Agent — replication, authority, matchmaking, sessions and persistence requirements.
- Server Agent — dedicated server configuration, jobs, economy persistence, permissions and operations.
- QA Agent — automated tests, gameplay verification, regression checks and acceptance criteria.
- Optimization Agent — frame time, memory, draw calls, asset budgets, streaming and network costs.
- Release Agent — packaging, versioning, store assets, release gates and rollback plans.

## Agent rules

1. Agents operate only within explicit project permissions.
2. Agents inspect the actual project state before changing it.
3. No invented asset IDs, engine objects, build results or test results.
4. Generated content must be attributable to its actual source and license status.
5. Every production task produces verifiable outputs or an explicit blocked state.
6. QA and validation are acceptance gates, not optional commentary.
